Dropbox setup

RPG Cards lets each user connect their own Dropbox app. No shared Dropbox app is required.

1. Create your Dropbox app

  1. Open Dropbox App Console and choose Create app.
  2. Select Scoped access.
  3. Select App folder.
  4. Give the app a name and create it.

The app name becomes the name of the folder created inside your Dropbox Apps folder (the folder may be translated differently in your Dropbox language). This is the folder where you should place JSON deck files so they are available in RPG Cards.

2. Enable permissions

In the app's Permissions tab, enable:

  • files.metadata.read
  • files.content.read
  • files.content.write

Click Submit or Save if Dropbox shows that button.

3. Add the redirect URI

In the app's Settings tab, under OAuth 2, add your app's exact URI:

Example 1

https://mephitrpg.github.io/rpg-cards/

Example 2 (for local development)

http://localhost:8080/

The final slash matters.

You can add multiple URIs if needed.

4. Connect RPG Cards

  1. Copy the app's App key from Dropbox.
  2. Return to the RPG Cards File panel.
  3. Paste the key into Dropbox App key.
  4. Click Connect Dropbox and approve access.
Only enter the App key. Never enter or publish your Dropbox App secret.

Troubleshooting

  • Invalid redirect URI: check that the URI matches exactly, including HTTPS and the final slash.
  • Access denied: verify both file-content permissions are enabled.
  • No decks appear: Dropbox files are stored in your app's dedicated App folder.
